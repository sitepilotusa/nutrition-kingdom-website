Drop a task here as a Markdown file. One task per file. Plain English. Example:

    # Add FAQ schema to the implant pages
    Use the questions already on each /services/dental-implants/* page. Do not invent answers.

The next run picks it up, does it if it fits the rules in AGENTS.md, and moves the file to
done/ with an outcome note at the bottom. If it does not fit the rules, the agent explains
why in the outcome note and leaves it for you.
